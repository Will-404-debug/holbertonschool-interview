# Linked List Cycle Detection

This project contains a function that checks if a singly linked list has a cycle.

## Files
- `lists.h` - Header file with struct and function prototypes.
- `0-check_cycle.c` - Implements the cycle detection function.
- `0-linked_lists.c` - Contains helper functions for managing the linked list.
- `0-main.c` - Test file to check functionality.

## Compilation & Usage

Compile the program using:
```sh
gcc -Wall -Werror -Wextra -pedantic 0-main.c 0-check_cycle.c 0-linked_lists.c -o cycle
